# 彩票助手

基于 Electron 的双色球 / 大乐透开奖查询与智能推荐桌面应用。

## 功能特性

- **实时数据** — 从 500彩票网 抓取 120+ 期历史开奖记录
- **智能推荐** — 5 组备选号码，基于热号分析、遗漏统计、AC 值筛选等策略生成
- **推荐绑定** — 推荐号码绑定下一期（未开奖期），非已开奖期
- **确认追踪** — 确认推荐后，开奖结果自动对比并显示命中情况
- **历史回顾** — 保存往期推荐记录及理由，随时查看战绩
- **双彩种** — 双色球、大乐透切换，数据独立存储
- **离线缓存** — 重启后自动恢复历史数据和推荐记录

## 技术栈

- Electron 28.3.3 + Node.js
- 数据源：500彩票网（datachart.500.com）
- 打包：electron-builder

## 开发

```bash
# 安装依赖
npm install

# 运行开发版本
npm run start

# 打包 Windows 便携版
npm run build
```

打包输出在 `dist2/win-unpacked/彩票助手.exe`（绿色便携版，无需安装）。

## 使用说明

1. 启动应用后点击 **获取最新记录**，自动抓取开奖数据
2. 推荐号码绑定**下一期**（还未开奖的那个）
3. 点击 **换一组** 切换其他备选方案，点击 **确认使用此推荐** 锁定
4. 下期开奖后应用自动显示命中结果
